# Web — макеты

Pencil-файла для веба нет: веб-дизайн вёлcя макетами (16 штук, 8 экранов × светлая/тёмная), а рабочая
реализация живёт в кодовой базе `dinamo-web`.

| Экран | Тёмная | Светлая |
|---|---|---|
| Вход | `w-01-login-dark.webp` | `w-01-login-light.webp` |
| Список чатов | `w-02-chat-dark.webp` | `w-02-chat-light.webp` |
| Диалог | `w-03-conversation-dark.webp` | `w-03-conversation-light.webp` |
| Звонки | `w-04-calls-dark.webp` | `w-04-calls-light.webp` |
| Контакты | `w-05-contacts-dark.webp` | `w-05-contacts-light.webp` |
| Настройки | `w-06-settings-dark.webp` | `w-06-settings-light.webp` |
| ЭДО | `w-07-edo-dark.webp` | `w-07-edo-light.webp` |
| Профиль | `w-09-profile-dark.webp` | `w-09-profile-light.webp` |

Общая логика, токены и решения — те же, что в мобильных досках (`dinamo-ios.pen`, `dinamo-android.pen`).
