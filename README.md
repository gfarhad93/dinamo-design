# Dinamo — дизайн iOS, Android и Web (редизайн 2026-10)

Исходники дизайна мессенджера «Динамо»: два файла Pencil (Pen.app) для мобильных платформ и макеты веба.
Открывать `.pen` в [Pencil / Pen.app](https://pencil.dev) — рядом лежат папки `assets/` и `images/`,
на которые ссылаются файлы (эмодзи, знак приложения, сгенерированные картинки).

| Платформа | Файл | Стиль |
|---|---|---|
| iOS (iPhone + ключевые окна iPad) | [`dinamo-ios.pen`](dinamo-ios.pen) | HIG, iOS 26, Liquid Glass только на функциональном слое |
| Android (телефон + планшет) | [`dinamo-android.pen`](dinamo-android.pen) | Material 3 Expressive |
| Web (десктоп) | [`web/`](web/) — макеты `.webp`, Pencil-исходника нет | тот же бренд, плотная десктопная сетка |

Превью без Pen.app: откройте [`preview/index.html`](preview/index.html) (или папки
[`preview/ios`](preview/ios), [`preview/android`](preview/android), [`preview/web`](preview/web)) — там экраны
входа, чатов, чата, звонков, контактов, ЭДО и настроек в тёмной и светлой теме.

## Что внутри

- **`dinamo-ios.pen`** — 11 дизайн-системных досок (цвета, типографика, форма и материалы, иконки, компоненты,
  пузыри «Заряд», типы сообщений, состояния, лента, анимации, поле ввода) + сценарии S1–S10
  (запуск и вход, навигация и список чатов, чат, профили и группы, звонки, контакты, ЭДО, настройки, системные
  поверхности, планшеты) + доска предложений.
- **`dinamo-android.pen`** — та же структура досок в идиомах Material 3 Expressive.
- **`web/`** — 16 макетов веб-интерфейса (8 экранов × светлая/тёмная тема). Веб-дизайн вёлся не в Pencil,
  а макетами; рабочая реализация — в кодовой базе `dinamo-web`.
- **`assets/`, `images/`** — ресурсы, на которые ссылаются `.pen`. Без них картинки в досках не отобразятся.

Тёмная тема — основная (каждый экран), светлая — для ключевых экранов каждого блока. Переменные цвета заданы
явными значениями `Light` / `Dark`, доски помечены темой.

## Ключевые решения

- **Пузыри «Заряд»**: свои сообщения в серии ярче к последнему (#0E52B8 → #1259C4 → градиент #1A68D6→#1663D0
  со свечением); форма углов зависит от позиции в серии; короткий хвост 8×12 только у последнего сообщения.
- **Серия** — один отправитель, один день, пауза ≤ 5 минут. В группах у последнего пузыря серии — аватар.
- **Статусы доставки различаются формой**, не только цветом.
- **Lock Mode** — бирюзовый (защита); красный только для ошибок и записи. Сообщения Lock Mode нельзя переслать.
- **Аватары — круг** на обеих мобильных платформах. Акцентная палитра из 12 цветов убрана: цвет пузырей задан
  брендом, у Android — бренд без Material You.
- **Подписание в ЭДО** — отдельный лист подтверждения; «Подписан» вычисляется по подписям текущей версии.
- **Новое поведение звонков — только под флагами** (`endScreenStaysOnFailure`, `callControlsAutoHide`,
  `selfViewDraggable1to1`), по умолчанию выключено.

Под каждым экраном в `.pen` — подпись: откуда пришли, что значит состояние, переход дальше (тип, длительность,
пружина или токен M3).
